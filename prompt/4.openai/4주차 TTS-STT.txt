STT, TTS 앱 만들기
# 목적
- streamlit과 stt/tts 앱을 만들기
- stt : speech to text
- tts : Text to speech

# 요구사항
- 너는 지금부터 openai api로 STT, TTS 를 코딩해줘.
- 왼쪽 sidebar에 작은 글씨로 STT, TTS 업로드할 파일이름을 선택할 수 있도록 해줘.
- 그리고 오른쪽 화면에는 STT 먼저 보여주고 그 아래 TTS를 보여줘.

# 생성 파일명
stt-tts.py (파일 이미 있으면 지우고 이 프로그램을 저장해주세요)

# STT 부분
- 왼쪽에 음성파일을 선택하면 이것을 오른쪽에 글자로 변경을 해줘. 
- 그리고 글자파일을 입력된 음성파일이름.txt로 저장해줘
- txt 파일을 저장할 때, full file path를 보여줘.
- 소리가 화면에 들리도록 해줘.
- stt, 경우 파일을 선택한후 "STT변환" 버튼이 하나씩있으면 좋겠어. 
- 새로운 파일이 선택이 되면 그에 맞도록 음성재생 및 STT 변환을 하도록 해줘.

# TTS 부분
- 왼쪽에 txt 파일을 선택하면 이것을 오른쪽 화면(TTS)에 텍스트 형태로 보여주고, 
- 이를 음성으로 읽어주고 이를 음성파일로 변경해줘.  
- 이때, 음성 voice를 선택할 수 있도록 해줘.
- 글자의 수가 많아지면, 글자를 잘라서 일단 한계치까지 음성으로 변환하고, 
- 나중에 변환된 음성을 모두 합해서 1개의 음성파일로 만들어줘. 
- 파일을 저장할 때, 입력된 텍스트파일이름.txt 로 해주고,full file path를 보여줘.
- TTS 경우 파일을 선택한후 "TTS변환" 버튼이 하나씩있으면 좋겠어. 
- 새로운 파일이 선택이 되면 그에 맞도록 음성재생 및 STT 변환을 하도록 해줘.

# 구현기술
- openai TTS model로는 tts-1을 사용하고 STT model로는 whisper-1을 사용해줘.
- .env 파일을 활용해줘.
- streamlit으로 화면을 깔끔하게 구현해줘.
