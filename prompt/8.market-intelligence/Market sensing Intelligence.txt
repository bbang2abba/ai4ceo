# 검색 대상 사이트 (Target Search Sites)
- 글로벌 IT 전문 매체: The Verge, CNET, Wired, TechRadar, Tom's Guide.
- 커뮤니티 및 SNS: Reddit (r/Samsung, r/Android), X (Twitter) 트렌드, YouTube Tech Influencers (MKBHD, Mrwhosetheboss 등의 영상 제목 및 댓글 반응).
- 글로벌 지역별 뉴스: Reuters (경제적 파급력), 동남아/유럽 현지 테크 블로그.

#. 수집 및 분석 데이터 항목 (Data Schema)
- 에이전트가 정보를 구조화할 때 반드시 포함해야 할 항목들입니다.
- 기본 정보: 매체명, 국가, 리뷰 날짜.
- 긍정 요소(Pros): 혁신성(폴딩 메커니즘), 화면 크기 대비 휴대성, 멀티태스킹 성능.
- 부정 요소(Cons): 내구성 우려(주름, 힌지), 가격 저항선, 배터리 효율, 무게/두께.
- 비교 분석: 기존 갤럭시 폴드 시리즈 및 경쟁사(화웨이 등) 모델과의 차별점.
- 전략적 인사이트: 마케팅 소구점, 차기 모델 수정 제안.
- 출처: website url

# 처리 로직
- 반드시 .env 파일을 사용해서 api key를 설치합니다. 

## 기본 대시보드 
- sidebar에는 마켓 리서치 제목을 받을 수 있는 칸을 만들어줘.
- 삼성전자의 브랜드 가이드라인(Navy & White)을 적용한 세련된 Streamlit 대시보드를 만들어줘. 
- 제목은 '삼성전자 Global Market Intelligence" 
- 기본적인 UI와 답변 스타일은 ref.py에 있는대로 해줘.
- 인터넷 검색도 ref.py에 있는 대로 gpt-5.2 web_search tool을 활용해줘.
- sidebar 버튼에서 <검색과 데이터수집> <감성분석> <임원보고서>

## 글로벌 실시간 검색 및 데이터 수집(<검색과 데이터 수집> 버튼)
- @Web 기능을 사용하여 sidebar에 받은 마켓리서치 토픽을 받고 위에서 정의된 검색대상 사이트에서 10개의 자료를 분석하고 Pandas DataFrame으로 정리하여 대시보드 메인 화면에 표로 보여줘.
- 시간이 많이 걸리므로 현재 몇개를 수집했는지 progress bar로
## 감성 분석 및 시각화 (<감성분석> 버튼)
- 수집된 데이터의 텍스트를 분석해서 장점과 단점을 요약해줘
- 특히 '내구성'과 '가격'에 대한 언급에 대한 요약과, 지역별로 반응이 어떻게 다른지 요약해줘."
- 각 평가마다 출처를 명시해줘. 출처는 매체명으로 해줘.

## 임원용 전략 보고서 자동 생성 (<임원보고서> 버튼)
- 분석된 결과를 바탕으로 DX 부문 부사장급 이상에게 보고할 '글로벌 런칭 초기 반응 보고서'를 작성해줘. 
- 보고서 스타일은 ref.py에 있는 대로 해줘.
- 1. 시장의 열광 포인트, 
- 2. 즉시 대응이 필요한 비판적 여론, 
- 3. 경쟁사 대비 우위 요소를 포함해야 해. 
- 4. 마케팅팀에 전달할 핵심 광고 카피 3개를 제안해줘.
- 5. DX 부분 임원이 follow-up 해야하는 3개 이슈들
