

SQL Agent 2

# 목표
- 먼저 cvs파일을 db 로 만들어서 질의에 대한 답변을 할 수 있도록 합니다. 
- 그리고 SQL Agent가 사용자가 입력하는 대로 SQL 를 생성해서 답변을 하도록 하는 코드입니다. 

# 파일명
- sql-agent2.py 만일 이미 존재한다면 지우고 다시 만들어주세요.

# 요구사항
- ref.py 의 RAG 경우처럼, cvs 파일을 선택하도록 합니다. 
- 선택된 cvs 파일을 db 로 바꿉니다. 
- 이때 db 명은 cvs파일명입니다. 
- 이때, 이미 열려있는 모든 데이터베이스를 close합니다.
- 데이터 베이스를 생성하면, 주요 테이블명, 컬럼명, 전체 row 수 등을 메인화면에 표시합니다. 
- 사용자가 질문을 하면, 이를 SQL로 변경하여 실행하고 답을 합니다. 
- Langchain의 AgentExecutor를 활용합니다. 
- 이때 시간이 많이 걸리므로, SQL progress를 표시합니다. 
- 답변을 표시합니다. 
- 그리고, 참고로 다음 질문 가능성이 높은 3개의 질문을 예시로 추천합니다. 
- 이때, 3개의 가능한 질문은 DB schema를 명확히 참조해서 실제로 답변 가능한 질문을 만듭니다.

- 인터넷검색, RAG는 필요없습니다.
