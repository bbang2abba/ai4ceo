구내식당sql.py
# 목적
- 이미 만들어진 구내식당.db를 활용해서 SQL로 분석하는 agent 작성

# 파일명
- 구내식당sql.py 로 저장해줘. 만일 파일이 이미 있으면 지우고, 다시 만들어줘.
- 구내식당sql.py는 프로젝트 루트에 만들어줘

# 요구사항
- sql-agent.py 파일을 활용해서, 구내식당.db 를 읽어서 sql agent를 streamlit 기반으로 만드는 코드를 짜줘.
- 모든 사용자 인터페이스는 ref.py 에 있는 것처럼 해줘.
- 그리고 사이드바에 구내식당 데이터 질문예시를 해줘.
- 또한 data를 보고 분석가에게 데이터분석을 통해 얻을 수 있는 인사이트를 제시해줘.
