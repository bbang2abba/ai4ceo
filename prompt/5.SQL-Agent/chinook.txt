SQL Agent 

# 목표
- 이것은SQL Agent가 사용자가 입력하는 대로 SQL 를 생성해서 답변을 하도록 하는 코드입니다. 

# 파일명
- sql-agent.py 만일 이미 존재한다면 지우고 다시 만들어주세요.
- 이 sql-agent.py 파일은 프로젝트 루트에 만들어주세요

# 요구사항
- 먼저 chinook.db를 읽습니다.
- 사용자가 질문을 하면, 이를 SQL로 변경하여 실행하고 답을 합니다. 
- Langchain의 AgentExecutor를 활용합니다. 
- 이때 시간이 많이 걸리므로, SQL progress bar를 표시합니다. 
- 답변을 표시합니다.
