youtube 내용 요약 및 QA
# 목적
- youtube-qa-bot.ipynb 이것을 참고해서 youtube 내용을 요약하고 Q&A를 할 수 있는 챗봇을 만들어줘
- streamlit으로 구현
- 파일명: youtube.py (파일이 이미 있으면 지우고 시작)

# 화면 설계
- ref.py 를 참고해서 설계해주세요

## 사이드 바 
- 모델 선택
  모델은 gpt-5.4, gemini-3-pro-preview, claude-opus-4-7
- youtube url 입력
- "동영상 처리하기" 버튼을 달아줘.
- 처리하는 진도를 0~100% 표시
- 다시 시작하기 버튼
	- 다시 시작하기 버튼을 누르면, 기존에 처리했던 url, 요약등을 없애주고 다시시작할 수 있도록 해줘. 

## 메인 화면
- 제목: Youtube Q&A Chatbot
- 입력창은 ref.py 와 같이 맨 아래 위치한다

# 동영상 처리방법
- 동영상은 매우 길기 때문에 2분 단위로 잘라서
- 각각을 동시에 처리하고 
- 종료후에 합해서 QA, 요약을 할 수 있도록 해줘.
- 각 LLM의 api key는 .env 파일에 있어.
